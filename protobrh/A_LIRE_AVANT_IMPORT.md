# Dossier du prototype

Déposez ici les fichiers du prototype téléchargés depuis Hostinger (dossier `public_html/brh/`).

**Avant de les envoyer sur GitHub :**
- ne déposez pas `.htpasswd` ni `.htaccess` (ils restent sur Hostinger) ;
- si `chatbot.php` contient la clé de l'API Mistral écrite en clair, demandez d'abord à Claude Code de la déplacer
  dans un fichier `config.php` (voir docs/PROMPTS.md, prompt n°2).

Vous pouvez supprimer ce fichier une fois le prototype importé.
